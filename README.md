# SAE Causal Signatures

**Does causal structure leave a signature in sparse autoencoder representations?**

📄 [Full technical writeup (PDF)](report/technical_note.pdf)

## Research Question

When two datasets have matched observable statistics (correlation, joint
probabilities, sparsity) but are generated by different underlying causal
structures, do sparse autoencoders (SAEs) learn systematically different
internal representations — or does the SAE only "see" the statistics, blind
to the generative mechanism behind them?

## Approach

Two synthetic datasets ("worlds") are constructed, each containing a target
feature pair (A, B) plus four independent distractor features:

- **World A — Direct dependency:** `A → B`. B's probability depends directly
  on A.
- **World B — Common cause:** `C → {A, B}`. A and B are each generated from
  a shared hidden cause C, and are correlated only because they share that
  cause — not because either causes the other. C is never observed by the
  SAE.

The two worlds' observable statistics (P(A), P(B), P(A,B), corr(A,B)) were
explicitly tuned to match closely, confirmed across multiple seeds (see
`notebooks/01_world_generators.ipynb`).

A small sparse autoencoder (linear encoder/decoder, ReLU bottleneck, L1
sparsity penalty) was trained separately on each world, across 5 random
seeds each, with a sparsity weight (λ = 0.03) selected via a systematic
sweep (see `notebooks/02_sae_training.ipynb`).

The resulting representations were compared using four progressively more
rigorous metrics (see `notebooks/03_representation_analysis.ipynb`):

1. **Raw feature recovery** — correlation between each latent and A / B.
2. **Partial correlation** — each latent's correlation with A (or B),
   controlling for the other, to separate genuine tracking from the
   shared A-B correlation.
3. **Best-latent-per-seed comparison** — comparing each seed's
   strongest-matching latent, avoiding invalid cross-seed latent-index
   averaging (see notebook note on a caught methodological error).
4. **Representation geometry** — aggregate inter-latent correlation
   structure, as a summary of how entangled/clustered latents are.

## Result

Across all four metrics, **World A and World B produced statistically
indistinguishable SAE representations**, with differences consistently
within normal seed-to-seed noise (roughly 0.01–0.06), not a systematic gap
between worlds.

This is consistent with the statistical hypothesis (H0): under these
controlled conditions, the SAE's learned representation appears to be
driven by observable statistics rather than by the underlying causal
generative mechanism.

## What This Does and Doesn't Establish

This result is specific to the tested setup: a small linear SAE, binary
synthetic features, and one particular strength of statistical matching.
It does **not** establish that causal structure never influences SAE
representations in general — only that, under these conditions, no
signature was detected by these four metrics. Different architectures
(deeper, nonlinear), richer feature types, or more extreme causal
structures might behave differently. This is a genuine negative result,
not a failed experiment.

Then open the notebooks in order (`01` → `02` → `03`) in Jupyter or VS Code.
Each notebook is self-contained and can be run top to bottom.

## Limitations

- Synthetic, low-dimensional data (6 features total) — not real language
  model activations.
- Small, linear SAE architecture — larger or nonlinear models may behave
  differently.
- Only one strength of causal/statistical matching was tested.
- Metrics are correlation-based; they may not capture all forms of
  representational difference (e.g., higher-order nonlinear structure).
